# Verification contract

The stock linter is pinned in tools/versions.env and installed through checksum-verified Go modules. Required commands are in CONTRIBUTING.md and the workflows. The explicit eight-linter profile checks correctness; gofumpt is the sole formatter. Build/vet, complete test discovery, native checks, independent PDF oracles, fuzz, mutation/control/scale campaigns, parser source reconstruction, secrets, vulnerability and packaging checks remain required. A local or cross-compiled result does not establish hosted/native release proof.

## Replaced enforcement

| Enforcement | Disposition / retained risk control |
| --- | --- |
| Implicit all-linter selection and universal naming/layout/complexity rules | Style preferences are reviewed directly; one formatter remains. No production field was removed merely to satisfy strict unread-field diagnostics. |
| Adjusted filename/source predicates and patched linter attribution | Active compiler display directives are rejected at physical AST positions in owned sources. Compiled import laundering control remains required. Build/embed/generate directives and literal negative-control fixtures remain supported. |
| Strict field-write semantics patch | Stock unused behavior; physical identity and occurrence-local form/link tests, independent oracles and mutation controls prove actual behavior. |
| Central source-regex lint registry and staleness jobs | Exact-file diagnostic rules below, explicit profile validation, real security/error/import controls. No folder-wide exclusions. |
| Global 100% reachable coverage and 41 excluded statements | Raw merged unit/executable statement coverage only, no exclusions. Empty executable evidence still fails. Required invariant matrices, independent oracles and deliberate mutant rejection establish their own properties. |
| Runtime parser source patches | Retained complete source reconstruction and original nested-module tests; not part of the linter retirement. |
| Mutation executor patch | Retained identity, worker census, artifact ownership, process cleanup and real negative controls. Baseline and mutants both use coverage instrumentation so Go 1.27 package receipts remain comparable. |
